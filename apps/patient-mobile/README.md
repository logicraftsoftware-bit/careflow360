# CareFlow360 Patient Mobile

React Native patient application with the CareFlow360 visual system.

## Included flows

- Patient home and healthcare services
- Doctor search and specialty filters
- Doctor profile, date/time selection and appointment booking
- Lab-test catalogue and cart
- Home/lab sample collection booking details

## Run Android

```bash
npm run start -w @careflow360/patient-mobile
npm run android -w @careflow360/patient-mobile
```

The Android application ID is `com.careflowpatient`, so it can be installed alongside the staff app.
